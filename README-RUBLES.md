# Скидка на доставку — оптимальная и своя сумма

Прототип: https://serj20001.github.io/delivery-discount-prototype-v2/rubles/

Макет: https://www.figma.com/design/OaolVHaabrE8Nv9upVA0wD?node-id=3573-111220

Это независимая копия версии `aa7e25b` из `SERJ20001/delivery-discount-prototype`. Исходный репозиторий не изменяется.

## Логика

- Старт — «Спецпредложения», далее каталог: 10 подходящих товаров, один подключённый Lime, ничего не выбрано. Состояние живёт в памяти до перезагрузки.
- Карточка, фото и чекбокс выбирают товар. При одном выбранном товаре доступны 100, 200, 300 ₽ и «Своя». Пресеты ограничиваются пределами товара и объединяются при совпадении. Начальная сумма — первый доступный пресет.
- При массовом выборе доступны «Оптимальная» и «Своя». Оптимальная — округлённая середина допустимого диапазона каждого товара. Вновь выбранные товары в массовом выборе получают оптимальную сумму. Если после изменения выбора остаётся один товар с оптимальной суммой, подставляется минимальный доступный пресет. Явное нажатие «Оптимальная» пересчитывает все выбранные товары.
- «Своя» открывает общий редактор с полем, линейным слайдером и клавиатурой. Начальное значение — медиана предпросмотров, ограниченная пересечением допустимых диапазонов, если оно существует. Границы слайдера — наименьший минимум и наибольший максимум выбранных товаров.
- Общая сумма ограничивается индивидуально для каждого товара. Карточка над полем показывает реальное число товаров ниже минимума или выше максимума. При необходимости видны оба пояснения. Это предупреждение, применение остаётся доступным.
- Карандаш у товара сразу открывает индивидуальный редактор с его фото и слайдером. Товар временно скрывается из фонового списка. Применение переносит его в подключённые; остальные выбранные товары сохраняют свои суммы.
- «Не применять», Escape и фон отменяют правку и возвращают товар, выбор и прокрутку. У подключённого товара только «Сохранить» и «Удалить скидку».
- В индивидуальном редакторе выход за пределы показывает тултип с фактической границей; подтверждение сохраняет ограниченное значение. Пустой ввод блокирует применение. Целые рубли, ввод 0–999999; крестиков очистки нет по прежнему запросу пользователя.
- Массовое применение снимает выбор и сохраняет вкладку. Если подходящих не осталось, вкладка скрывается и открывается «Со скидкой». Снизу появляется закрываемый тост с реальным числом товаров.
- Плашка выбора чёрная: «Выбрать все» при пустом выборе, иначе количество. Фиолетового AI-баннера нет.

## Пределы и данные

Неизменённая модель: `percent/discount-model.js`. Примеры: 300 → 30–210; 400 → 30–280; 500 → 30–350; 900 → 50–600; 1500 → 50–660; 5000 → 110–1150; 10000 → 110–1230; 70000 → 310–4600 ₽. Между примерами линейная интерполяция, минимум вверх, максимум вниз.

Каталог — `rubles/catalog.js`. Реальные счётчики и суммы вычисляются из каталога. У серых Salomon цена 3 000 ₽ во всех состояниях. Примерные числа 32/45/33, фиксированные 50–1500 и противоречивые цены из макета не подставляются. Граница и позиция слайдера линейно соответствуют действительным пределам.

## Исходники и запуск

Рабочие файлы: `source/rubles.template.html`, `rubles/app.js`, `rubles/style.css`, `rubles/motion.js`, `rubles/catalog.js`. Общая стартовая страница — `source/entry-screen.*`.

```sh
rtk proxy node source/build-rubles.mjs
rtk proxy python3 -m http.server 8802 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8802/rubles/`. `#delivery` — вход непосредственно в каталог для QA.

`rubles/index.html`, `rubles/build.json`, `rubles/discount-model.js` и `exports/delivery-discount-rubles.html` генерируются сборкой. Их не редактировать вручную. Автономный HTML содержит все ресурсы.

## Ассеты и движение

Оригинальные фото и графика сохранены. Новые SVG чекбоксов, карандаша, тега и закрытия тоста получены через Figma. Происхождение — `asset-manifest-rubles.json`, сценарии — `flow-rubles.json`. Code Connect ссылается на отсутствующий в этом статичном проекте `Stiletto_Test/ui.html#send.btn-text`, поэтому сохранены существующие HTML-кнопки.

Локальные шрифты: `rubles/assets/avito-sans-text-regular.woff2` (400), `avito-sans-text-medium.woff2` (500), `avito-sans-text-bold.woff2` (700). Существующий Avito Sans Text сохранён; клавиатура системная. Изображения и шрифты декодируются до открытия приложения; при ошибке доступен повтор.

Панель и клавиатура выезжают одним блоком за 320 мс и закрываются за 280 мс. Карточка переходит из списка за 320 мс, возвращается за 260 мс; список смыкается за 280 мс. `cubic-bezier(.22,.8,.25,1)`. Для reduced motion переходы немедленные. Chrome interactivity/inert исправление сохранено.
